========================================
PROJECT ANALYSIS: deadlocked
========================================

1. OVERVIEW
----------------------------------------
  Name:        deadlocked
  Description: Linux-only cheat/assist tool for Counter-Strike 2 (CS2)
   Features:    Aimbot, ESP (wallhack), Triggerbot, Recoil Control (RCS),
                No-flash, FOV changer, Smoke disable, Grenade lineups,
                Glow (wallhack glow through walls)
  Author:      avitran0
  Repository:  https://github.com/avitran0/deadlocked
  License:     GPL-3.0
  Platform:    Linux only (enforced at compile time)
  Language:    Rust (edition 2024)
  Version:     1.0.0

  Architecture: Two-threaded (GUI thread + Game thread) communicating
                via a channel. Shared state via Arc<Mutex<Data>>.

  Thread 1 (GUI): winit event loop, egui UI, OpenGL overlay rendering
  Thread 2 (Game): GameManager loop at ~100Hz, memory read/write via
                   process_vm_readv/writev, feature execution

7. ARCHITECTURE DETAILS
----------------------------------------
  main() spawns two threads:
    GUI Thread: winit event loop with egui + OpenGL overlay
    Game Thread: GameManager running CS2 struct's main loop

   Game Loop (~100Hz):
     1. Update input state
     2. Read entity list (cache)
     3. BVH visibility check
     4. Disable smoke (if enabled)
     5. Glow (write CGlowProperty on enemy pawns each frame)
     6. No-flash (if enabled)
     7. FOV changer (if enabled)
     8. ESP toggle (if hotkey pressed)
     9. Triggerbot (if enabled)
     10. Find target (FOV/distance based)
     11. Aimbot + RCS (if enabled)
     12. Update shared Data struct

13. SAFETY NOTES
----------------------------------------
  - read-only cargo feature disables all memory writes
  - Crash handler sends stacktraces to author (opt-out configurable)
  - Uses uinput (virtual mouse device named "TI-84 Plus Silver Calculator")
  -    - Unsafe features (no-flash, FOV, smoke, glow) flagged with VAC risk warnings
   - Glow writes to inline CGlowProperty at C_BaseModelEntity + 0x0d58
     (m_fGlowColor=0x08, m_bGlowing=0x51, m_nGlowRange=0x38,
      m_iGlowType=0x30, m_glowColorOverride=0x40 within CGlowProperty)
